# Specification

Define which normalized records are mirrorable. Require `source_kind=post` or a platform-equivalent post type; retain public profile snapshots as archive metadata only. Add `public_name` for concise mirror-facing names such as `ACC`, while preserving canonical agency identity. Validate long-post rendering and provenance links.

Acceptance requires profile snapshots to be rejected, actual posts to render deterministically, and `ACC` to appear in public-facing mirror metadata.
