# Frontend Style Guide

## HTML5
- Use semantic HTML5 tags (<header>, <main>, <section>, <footer>, <article>)
- All images must have alt tags for accessibility

## CSS3
- Define theme tokens as CSS Custom Properties in :root
- Use Flexbox and CSS Grid for responsive design
- Avoid floats and inline styles
- Use lowercase hyphen-separated class names

## JavaScript (ES6+)
- Use const and let; avoid var
- Use ES6+ modules and arrow functions
- Use async/await with try/catch for async operations
