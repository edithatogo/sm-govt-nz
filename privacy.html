Privacy Policy

Privacy information for the NZ Government Bluesky Syndicator and its mirror accounts.

Last updated: 14 June 2026

This project mirrors and archives public posts from selected official public-sector accounts for transparency, accessibility, resilience, and research use. Source accounts remain authoritative.

Information We Process

The project processes public posts, public profile metadata, public links, timestamps, media references, and platform identifiers from configured source and mirror accounts. It does not intentionally collect private messages, non-public account data, payment details, or sensitive authentication data from visitors.

How Information Is Used

Public source material is used to operate mirror accounts, maintain public archives, publish transparency dashboards, deduplicate records, validate source health, and prepare public research datasets.

Platform Tokens

Platform access tokens are stored only as GitHub Actions secrets or local developer environment variables. They are used to validate account identity and, where explicitly enabled, publish mirror posts from dedicated mirror accounts.

Website Visitors

This static GitHub Pages site does not run custom analytics, advertising trackers, or visitor profiling code. GitHub may process standard request logs as part of hosting the site.

Contact

For privacy or data deletion requests about this project, open an issue at github.com/edithatogo/sm-govt-nz/issues.
