Use the onboarding heuristic agent before each attempt. It learns from sanitized outcomes only and may choose between the headed UC/CDP plan, a headed standard-CDP fallback, and an operator checklist. It must stop at registration submission, CAPTCHA, age assurance, email verification, or any unexpected security challenge.
