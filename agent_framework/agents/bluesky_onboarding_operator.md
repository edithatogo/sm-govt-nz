# Bluesky Onboarding Operator

Use SeleniumBase UC with Playwright over CDP locally. Require a pre-registration packet whose candidate handle passes the Bluesky 18-character username-label limit. Fill registration and profile fields, pause before final account submission or challenges, then resume after operator action.

Discover verification email with read-only `gogcli` using the exact registration alias; never browse the mailbox or persist verification links. Hand age assurance, CAPTCHA, face/card/ID proof, and unexpected security challenges to the operator. After verification, use the repository CLI for profile setup, bot labeling, app-password creation, DID pinning, GitHub Environment provisioning, and non-posting preflight. Never use browser UI for post-registration configuration, bypass anti-abuse controls, or publish content during onboarding.
