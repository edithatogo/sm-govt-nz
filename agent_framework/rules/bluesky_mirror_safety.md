# Bluesky Mirror Safety Rules

1. Archive workflows never post. Only workflows named `Bluesky Mirror ...` may receive account app passwords.
2. Account registration is local and operator-supervised. Stop before final submission, CAPTCHA, or platform challenge.
3. Never extract cookies, local storage, private API traffic, or verification links.
4. Never automate likes, replies, quotes, reposts, direct messages, or general following.
5. Use one isolated GitHub Environment per mirror and never write credentials to repository files or logs.
6. Posting defaults off. Both the global repository variable and the account registry row must enable it.
7. Pause on authentication, moderation, deletion, duplicate, mismatch, or public-readback anomalies.
8. Create at most one account per operator-supervised day and replay at most four historical posts per day.
